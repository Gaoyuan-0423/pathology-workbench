# Pathology Workbench · 病理工作台

支持 IHC H-DAB、H&E/Masson 染色定量、细胞核分割、RGB 双通道 IF 共定位及报告导出的**纯前端网页工具**。所有计算在浏览器本地完成，图像数据不经任何网络传输。

## 功能

- **场景入口**：IHC、常规与特殊染色、IF 分组进入；H&E / Masson 在染色模式内选择，非核计数场景默认收起核分割设置。详见[场景使用与发布交接](docs/scene-modes.md)。
- **导入**：PNG / JPEG / TIFF（8 与 16 bit，多页取最大页）。16 bit 按固定 v/257 标尺映射到 8 bit，**不做逐图对比度拉伸**；厂商全切片格式（.svs/.ndpi/.mrxs 等）请先从采集软件导出普通 TIFF
- **颜色去卷积**：Ruifrok 2001 标准苏木精–DAB 向量，在 DAB 光密度通道（OD = 255·ln(255/(I+1))/ln255，0–255 标尺）上定量
- **背景扣除**：全图 OD 百分位（默认 5）
- **阳性阈值**：Otsu / Triangle / 均值+2σ / Kapur 最大熵 逐图自动；手动；**未染色对照片自动标定**（按允许假阳率取对照分布分位，默认 0.1%）
- **细胞核分割**：苏木精通道逐图 Otsu + 8 连通域；面积/圆度门控；**触边目标边界折算计数**（n + b·n/(n+b)）；标定 μm/px 后输出细胞密度（个/mm²）
- **多 ROI**：画布框选，逐 ROI 与整图并行统计
- **IF 整图与矩形 ROI**：背景和阈值在整图计算一次，固定应用于各 ROI；分别输出全区域/掩膜 Pearson、Manders M1/M2、实际区域与掩膜像素计数。不可计算的系数留空并说明原因。IF 结果库保存原图、配置和全部区域结果，可载入历史配置复算；提供专用 CSV、Excel 表和 Methods。确认 IF 独立设计后可按所选系数汇总至实验单位，像素/ROI 数不作为独立 n。详见 [IF 区域分析与归档](docs/if-regions.md)及 [IF 实验单位统计](docs/if-experimental-units.md)。
- **批处理**：一次选择多张图像，按当前预设与参数逐张分析并写入样本库（不替换当前画布、不保留像素、可取消、逐文件报错）
- **实验单位与组间统计**：整图样本记录显式关联独立单位、切片、视野和来源；确认独立设计后，先去重视野，再做切片内视野均值与单位内切片等权均值，每单位向组贡献一个值。分别报告记录数、图像数和 nBio；未确认、身份冲突、混合/未知预设或不足独立重复时保留描述并阻止推断。支持 Welch t / ANOVA + Dunnett，以及秩检验与 Holm 校正；检出多组异方差时不计算普通 ANOVA/Dunnett。详见[实验单位与统计范围](docs/experimental-units.md)。
- **一键体检（诊断 API）**：对图像质量、阈值可靠性、核分割、工作流与统计配置做 20 余项自动化检查，输出分级问题与可操作优化方向；内置程序化 API（`window.__pathologyAPI`，控制台可调 `getReportJson()` / `exportReportJson()`），报告可导出 JSON/Markdown
- **AI 核分割（可选）**：加载自定义 `.onnx` 分割模型（onnxruntime-web 本地推理，兼容输出单通道核概率图的 U-Net 类模型、动态 [1,1,H,W] 输入），用 AI 概率图（阈值 0.5）替代苏木精 Otsu；失败自动回落。模型仅驻留内存
- **染色向量微调**：去卷积双色向量可按本地染色协议调整（高级面板），Methods 中明示数值
- **出版导出**：Excel 保留原始记录、设计、切片/单位汇总和组描述，仅在满足推断条件时加入统计检验；CSV 分离原始记录与单位值。柱状图 SVG/PNG 标注 nBio，少于两个有效单位时不画 SD；支持阳性掩膜叠加 PNG 及**中英双语 Methods**，区分当前图像设置与历史样本库统计范围。

## 方法学要点

| 项目 | 定义 |
|---|---|
| 光密度 | OD = 255·ln(255/(I+1))/ln255，0–255 标尺（Ruifrok 惯例，+1 钳制） |
| 去卷积向量 | 苏木精 (0.684, 0.696, 0.183)、DAB (0.250, 0.500, 0.850)，残差向量取正交补 |
| 阳性判定 | DAB OD 严格大于阈值（背景已扣除） |
| 圆度 | 4πA/P²，P 为 4 邻域边界边计数周长（系统性偏低估，门控默认值宽松） |
| 边界折算 | estimated = n + b·n/(n+b) |
| 阳性核 | 核内平均 DAB OD > 阳性阈值 |

正态性检验为 D'Agostino–Pearson K²；少于 8 个有效独立单位或检验不可计算时显示“正态性未知”。至少两个组、每组至少两个有效独立单位仅是程序生成推断的最低门槛，不保证研究功效或检验假设成立。Mann-Whitney 使用近似算法；参数与非参数结果须按预声明分析方案解释，不按显著性择优报告。

## 隐私与数据纪律

- 纯前端 + IndexedDB 本地自动保存，无任何网络请求（更新检查仅在打包版通过 CI 注入，网页部署不包含）
- 本仓库测试全部使用**程序化合成图像**，不含真实实验数据

## 中英文界面

右上角可切换中文 / EN 并记住选择；跨站导航同步语言，切换不清空图像和分析结果。维护与验证约定见 [中英文界面](docs/bilingual-ui.md)。

## 开发

```bash
npm install
npm run dev        # 开发服务器
npm test           # Vitest 单元测试（算法手算对照）
npm run build      # tsc -b && vite build
npx playwright test  # E2E 冒烟（自动起 dev server）
npm run lint       # oxlint
```

## 部署

GitHub Actions 两段式：`ci.yml`（单元测试 + 构建 + E2E）产出经校验的 `web-dist` artifact；`pages.yml` 手动 dispatch、校验指定 main 提交确有成功 CI 后才部署该构建到 GitHub Pages——只部署验证过的版本。
