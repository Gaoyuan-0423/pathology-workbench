# 病理分析场景入口

页面顶部提供三个场景，图像画布、ROI、标尺和现有分析能力继续共用。

| 场景 | 预设或任务 | 参数展示 |
| --- | --- | --- |
| IHC 免疫组化 | H-DAB | DAB 阈值、背景与细胞核分割直接显示 |
| 常规与特殊染色 | H&E、Masson | 先选染色预设；细胞核分割与 AI 核分割默认收起，可展开调整 |
| IF 免疫荧光 | RGB 双通道共定位 | 通道 A/B、各通道阈值、背景与掩膜叠加 |

## 使用方式

1. 选择场景；常规与特殊染色还需选择 H&E 或 Masson。
2. 导入图像，按需要框选 ROI 或标定比例尺。
3. 调整对应参数，在图像下方核对结果与掩膜，再使用现有导出功能。

切换场景不会删除当前图像、ROI 或标尺。当前会话内返回“常规与特殊染色”时，会使用上次选择的 H&E 或 Masson。旧版保存的项目继续使用相同的本地存储格式，并按其预设显示所属场景；无图像时选择的模式也可以保存和恢复。

本轮只调整入口、参数呈现及切换时的结果刷新。阈值、核分割门控和样本库继续使用当前项目的设置，切换染色后应核对这些参数。折叠核分割设置不会停止核分割计算；结果指标、算法、默认数值与导出格式保持原有定义。IF 当前仍是 RGB 图像的双通道共定位，不增加原始多通道或 Z/T 数据读取能力。
