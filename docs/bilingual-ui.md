# 中英文界面

右上角 **中文 / EN** 切换当前界面语言；图像、ROI、标尺、参数、分析结果和用户输入保持不变，切换语言不会重新发送分析请求。

- 有效 URL 参数 `?lang=zh` / `?lang=en` 优先，其次为本域 `localStorage['wisplab.lang']`，默认中文。有效 URL 选择会写入存储；存储不可用时仍可使用 URL 和内存中的选择。
- 切换使用 `history.replaceState`，保留其他查询参数和 hash；同步更新 `document.documentElement.lang` 与页面标题。
- WB / 病理 / PCR / 总首页链接携带 `lang`，以便跨域保持选择。GitHub Pages 和本地域名仍遵循原有导航目标规则。
- `src/i18n/messages.ts` 保存显式文案与动态模板，UI 用 `t()` / `tError()` 翻译。没有整页 DOM 替换。引擎、状态与分析判定值保持原值，错误和诊断只在呈现时翻译。
- 文件名、用户设置的分组/样本名、ROI 名称、数字和科学符号不翻译。默认分组在尚未输入时跟随语言；输入后保留原文。默认 `ROI 1` 等名称本身适用于两种语言。
- 结果、质量检查、图表、Excel/CSV 标签和 UI 报告导出跟随当前语言；Methods 仍保留既有中文与英文两个段落。程序化核心 API 保持既有结构与字段值。

验证包括原有算法与场景测试，以及 URL 优先级、存储受限、跨站链接、切换后数据/数值保留、无新增分析请求、全场景和展开面板文案、可访问性属性、导出内容和 320/390px 布局。
